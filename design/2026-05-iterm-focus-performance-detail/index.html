设计核心一句话：把"点击 row → iTerm 在前"的瓶颈拆成两段 — 主线程用 NSRunningApplication.activate（~0.3 ms）让宿主立刻前置， pane 精度的 NSAppleScript 调用（40–200 ms）扔到单线程 QThreadPool 异步落地。 现有 subprocess osascript 路径保留为 fallback，PyObjC 不可用时自动降级。
Goal 速查
G1 主线程 ≤ 5 ms · G2 端到端 ≤ 50 ms p95 · G3 pane 精度不退化 · G4 PyObjC 缺失降级 · G5 其他 dispatch 不变
