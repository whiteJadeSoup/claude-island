⌘ Palette research · 2026-05-22

From cold blueprint
to warm workshop.

The current claude-island uses GitHub Primer's cool near-black with four highly saturated phase colours competing for attention. This document proposes a re-calibration to Catppuccin Mocha — a pastel palette beloved in the developer community for its low-contrast warmth and harmonious accent set. Both candidates are rendered live below using the same DOM, so the visual diff is direct.

The same panel, two palettes.

Identical DOM, identical content. The only differences are the CSS variables. The animated wave in the rate slot runs in both — note how the new palette's mauve / sage / sapphire pulse less aggressively than the old pure purple / pure green / pure blue.

/03 — Three design moves

Why this palette specifically.

The proposal is not "just dim the colours" — it's three deliberate moves drawn from how the developer community uses long-running dark themes.

i/01

Pastel beats saturated when four colours coexist

The panel can have up to four phase colours visible simultaneously (thinking purple, tool-use green, waiting orange, compacting blue). At GitHub Primer's saturation level they all reach equally hard for the eye. At Catppuccin's pastel level the hue still distinguishes them but each one recedes when it's not the focus.

ii/02

Warm dark feels like a workshop, cold dark feels like a server room

Catppuccin's #1e1e2e base has a slight purple-blue cast that the eye reads as "warm dark wood" rather than "cold concrete". Same darkness value, very different emotional register — and the same backdrop that the most popular Neovim and VS Code themes are now built on.

iii/03

Cost colour should signal magnitude, not panic

The current palette puts $58 in the same orange as $394. That trains the user to ignore the colour. The new tiers — calm grey under $5, sunshine yellow $5–10, friendly maroon $10+ — keep the same threshold structure but let the high tier actually mean "look here", because the low tier doesn't.

/04 — Implementation

Tokens move. Code doesn't.

Because the v4c code already routes everything through lab_palette.py, this entire migration is ~30 lines of token value replacement plus a handful of scattered hex literals (_STYLE_COST_MID, the waiting row tint, capsule wave colours).
